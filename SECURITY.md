# Security Policy

## Reporting a vulnerability

**Do not create a public GitHub issue for security vulnerabilities.**

Email **security@opencomplai.com** with a description, steps to reproduce, the potential impact and,
if you have one, a suggested fix. We aim to acknowledge reports within 48 hours.

### Scope

In scope: `action.yml`, `run.sh` and `comment.sh` in this repository (for example script injection
through inputs, token handling, or the pinned dependencies).

Out of scope: the `opencomplai` command-line tool itself, which has its own policy in the
[opencomplai repository](https://github.com/Opencomplai/opencomplai/security/policy).
